# Conversor-de-DUIMP
Conversor de DUIMP para DI para realização de cadastro do sistema RENAVAM

Aplicação web desenvolvida em HTML, CSS e JavaScript para converter o número da DUIMP (Declaração Única de Importação) em DI (Declaração de Importação), conforme a regra de conversão utilizada para cadastros de veículos no sistema RENAVAM.

# Projeto
Com a implantação da DUIMP, ainda existem processos e sistemas que utilizam a numeração da antiga Declaração de Importação (DI). Durante as atividades realizadas na SENATRAN, minha equipe e eu precisávamos realizar essa conversão frequentemente para efetuar cadastros e complementações de dados de veículos no sistema RENAVAM.

Para tornar esse processo mais rápido, seguro e evitar cálculos manuais, desenvolvi esta aplicação. Basta informar o número da DUIMP e o sistema realiza automaticamente a conversão para a DI equivalente.
